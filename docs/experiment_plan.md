# Experiment Plan (Future Work)

## Experiment 1: Adaptive vs Fixed Curriculum

**Question:** Does adaptive difficulty improve self-reported imagery stability compared to fixed difficulty?

**Design:** Within-subjects, counterbalanced. N=20+. Each participant completes two sessions: one adaptive (staircase), one fixed at Level 3.

**Measures:** IQI trajectory, self-reported vividness/stability, VVIQ pre/post.

## Experiment 2: Self-Report Only vs Simulated EEG-Assisted

**Question:** Does incorporating simulated EEG-like features improve feedback quality compared to self-report-only feedback?

**Design:** Between-subjects. One group uses full pipeline; control group uses only self-report for state estimation.

**Measures:** Session engagement, IQI variance, subjective feedback quality rating.

## Experiment 3: Visual-Only vs Visual + Audio Guidance

**Question:** Does adding audio cues (breathing tone, verbal prompts) improve imagery stability?

**Design:** Within-subjects. Audio vs silent conditions.

**Measures:** Self-reported stability, task completion rate, fatigue trajectory.

## Experiment 4: Longitudinal Corridor Stabilization

**Question:** Does repeated practice with IMAGINA improve self-reported imagery vividness over weeks?

**Design:** Single-group longitudinal. N=10+, 3 sessions/week for 4 weeks.

**Measures:** VVIQ at weeks 0, 2, 4. IQI/PID trends across sessions.

## Experiment 5: Catch Trials and Placebo Controls

**Question:** Can users distinguish adaptive feedback from random feedback?

**Design:** Within-session catch trials where feedback is randomized for 3 windows.

**Measures:** Detection rate, self-report during catch vs normal windows.

## General Notes

- All experiments require IRB/ethics approval.
- Informed consent must clearly state that IMAGINA is experimental.
- Data should be anonymized and stored locally.
- Results should be published with full methods, code, and data.
