# C3M — Analysis Specification

Companion to `C3M_PROTOCOL.md`. This file fixes the exact estimators, notation, and frozen
constants used in C3M so that every result is reproducible and no degree of freedom is left to
post-hoc choice.

---

## 1. Notation and frozen quantities

- Voxel space: `V = 15587` voxels (nsdgeneral ∧ ncsnr > 0), the identical ROI union used to
  train the frozen C3 decoder. The voxel coordinate list is frozen and hashed.
- Frozen C3 decoder `D`: `weights W ∈ R^{V×768}`, `bias`, `voxel_mean μ_p ∈ R^V`,
  `voxel_std σ_p ∈ R^V` (these are the **perception-train** per-voxel statistics),
  `target_mean t̄ ∈ R^768`. `weights_hash = df2dfd8961d7f7385f00ab25fd69e18c33923e6508b9fe16c3b74b015dd4f9f1`.
  Prediction: `ŷ(x) = ((x − μ_p)/σ_p) W + bias + t̄`.
- Candidate pool `C ∈ R^{12×768}`, L2-normalized CLIP ViT-L/14 embeddings, frozen order
  (Set A = pool indices 0–5, Set B = 6–11). `candidate_pool_hash` recorded.
- Beta matrices (raw int16 → float32, **no scaling**, matching C3 extraction):
  - `X_p` core-NSD perception ROI betas (reference; regenerated by rolling extraction).
  - `X_v` NSD-Imagery **vision** betas: 96 trials (Set A 48 + Set B 48), from rows
    `visA = 0:48`, `visB = 192:240` of `betas_nsdimagery.hdf5`.
  - `X_i` NSD-Imagery **imagery** betas: Set B primary = rows `imgB_1 = 336:384` ∪
    `imgB_2 = 624:672` (96 trials); Set A secondary = `imgA_1 = 144:192` ∪ `imgA_2 = 576:624`.
  - Row mapping is the C3-certified mapping (`results/c3_nsdimagery_row_mapping.json`,
    `results/c3_nsdimagery_beta_event_manifest.json`), reused unchanged.

A session-alignment transform is a map `T: R^V → R^V` applied to imagery-session betas
**before** the frozen decoder's own z-scoring:
`ŷ_aligned(x) = D.predict(T(x))`, where `D.predict` internally applies `(·−μ_p)/σ_p`.

## 2. Alignment methods

Let `x` be a raw ROI beta vector from the NSD-Imagery session (vision or imagery). Statistics
below with subscript `s` ("session") are computed from **NSD-Imagery vision betas only**, and
under the leakage rule of §5 of the protocol (target-blind for Family A; train-target subset
for Family B, evaluated on held-out targets).

### Family A — target-blind

- **M0 identity:** `T(x) = x`.
- **M1 mean correction:** `T(x) = x − m_s + μ_p`, where `m_s` is the per-voxel mean of the
  (pooled, unlabeled) NSD-Imagery vision betas and `μ_p` the frozen perception train mean.
  (Global-scalar variant reported alongside: `T(x) = x − mean(m_s) + mean(μ_p)`.)
- **M2 affine (shift + scale):** per-voxel `T(x)_v = (x_v − m_{s,v}) · (σ_{p,v}/σ_{s,v}) + μ_{p,v}`,
  with `σ_s` the per-voxel std of NSD-Imagery vision betas.
- **M3 CORAL / shrinkage covariance alignment:** whiten with the shrunk session covariance and
  recolor with the shrunk perception covariance:
  `T(x) = (x − m_s) Σ_s^{−1/2} Σ_p^{1/2} + μ_p`, where `Σ_s, Σ_p` are Ledoit-Wolf-shrunk
  covariances. For `V ≫ n`, computed in the low-rank subspace spanned by the centered
  session betas (see M4); shrinkage intensity is a **frozen** grid selected by held-out VISION
  reconstruction, never by imagery.
- **M4 low-rank distribution alignment:** project onto the top-`r` session PCs, match the
  first two moments in that subspace, map back; `r` chosen from a frozen grid by held-out
  vision performance.

### Family B — vision-calibrated (fit on train-target vision betas, eval on held-out targets)

- **M5 ridge voxel-space session map:** regress perception-space beta targets on
  imagery-vision betas per target-mean, `T = argmin_A ‖A X_v^train − X_p^match‖² + λ‖A‖²`.
  Because `X_p^match` (the matched perception representation of the same seen image) is only
  available for images that also appear in core NSD, M5 uses the **shared** vision targets and
  is evaluated strictly on held-out target identities. λ from a frozen grid via inner CV on
  **vision** folds.
- **M6 regularized low-rank session map:** M5 constrained to rank `k` (reduced-rank
  regression); `k, λ` frozen grid, inner vision CV.
- **M7 orthogonal / Procrustes:** `T = argmin_{Ω: ΩΩ^T=I} ‖Ω X_v^train − X_p^match‖²` solved
  in a shared low-dim subspace (SVD of the cross-covariance). Applied where dimensionally
  appropriate (subspace Procrustes, not full-`V` orthogonal).

Every Family-B method is fit only on the **training** target identities of a LOTO/L2TO split
and scored only on the **held-out** target(s).

## 3. Metrics (per method, per held-out fold, then aggregated)

- **MRR** over the 12-candidate pool (primary: restricted to the correct set's 6 candidates
  for per-set reporting; full-12 reported alongside). Rank of the true candidate by cosine.
- **top-1 / top-3 / top-5 accuracy**, **median rank**.
- **true 2AFC**: fraction of (trial, foil) pairs where the true candidate is more cosine-similar
  to the prediction than the foil candidate; chance 0.5; ties scored incorrect (as in C3).
- **candidate-score entropy**: Shannon entropy of the softmax over within-set candidate
  cosine scores, averaged over trials, normalized to [0,1] by `log(n_set)`; low entropy ⇒
  peaky/collapsed.
- **dominant-candidate fraction**: from `prediction_collapse_diagnostic` (C3 module reused
  unchanged); degenerate iff > 0.5.
- **prediction-covariance effective rank**: `exp(H(λ̃))` where `λ̃` are the normalized
  eigenvalues of the covariance of the predicted embeddings across trials; a collapsed decoder
  has effective rank ≈ 1.

Chance references: 6-candidate MRR chance = `H_6/6 ≈ 0.408`; 12-candidate chance from the C3
artifact (`0.2586`). 2AFC chance = 0.5. All reported explicitly next to each metric.

## 4. Nulls and significance

- **Held-out-target vision permutation null:** within each fold, permute the target labels of
  the held-out trials (repeat-preserving) and recompute MRR; aggregate across folds; report the
  exact/Monte-Carlo p. Because folds are small, the **aggregate** statistic is the primary one.
- **Matched random transform control:** for each fitted method, generate a random transform of
  matched capacity (same rank / same number of free parameters, random orthogonal or random
  Gaussian as appropriate, fixed seed `20260822`) and confirm it does **not** reproduce the
  improvement. Report the improvement distribution over ≥ 200 random matched transforms.
- **Imagery exact null (only post-unblinding):** 6! = 720 target-identity permutations,
  repeat-preserving, as in C3; Monte-Carlo 100k, seed `20260724` (identical convention to C3
  for comparability).

---

## 5. Frozen MEOI (metric of interest) and success thresholds

- **Primary MEOI:** aggregate **held-out-target Set B MRR** under M-of-choice, subject to the
  four guard conditions (no collapse, 2AFC > 0.5, held-out improvement, not reproduced by
  matched random).
- **"Meaningful improvement over identity":** the held-out-target Set B MRR must exceed the M0
  identity MRR by an amount that also clears the 95th percentile of the matched-random-transform
  improvement distribution, AND the aggregate held-out permutation p < 0.05.
- **Non-degenerate:** dominant-candidate fraction ≤ 0.5 on held-out trials.
- These thresholds are frozen in `results/c3m_protocol_decision.json` and are **not** revised
  after seeing results.

## 6. Determinism, provenance, reproducibility

- All RNG seeds fixed: alignment/matched-random `20260822`; imagery MC null `20260724`.
- Every runner writes: input data SHA-256 (betas file), frozen decoder `weights_hash`,
  candidate pool hash, ROI voxel-coord hash, git SHA, and its own result-object self-hash.
- No machine-specific paths in reusable runners: data roots via `NSD_DATA_ROOT`,
  `NSD_BETAS_ROOT`, `NSD_CACHE_ROOT`; imagery betas via `NSD_IMAGERY_BETAS` (fallback to the
  standard `nsdimagerybetas_fithrf/betas_nsdimagery.hdf5` relative path under the betas root).
- Heavy optional deps (h5py, nibabel) are lazy-imported so CI test collection never requires
  them.
- Prohibited git operations (reset --hard, clean, checkout -- ., restore .) are never used;
  prior valid states are preserved by amendment.
