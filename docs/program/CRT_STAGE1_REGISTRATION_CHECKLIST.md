# CRT Stage 1 registration checklist

**Status:** not ready. Every unchecked item is a blocker. Do not submit a Stage 1 report until the
checklist is complete and the code is frozen.

## 1. Science

- [ ] Target-scale NUTS SBC `PASS` or a documented narrowed claim.
- [ ] Recovery `PASS` or a documented limitation.
- [ ] Design pairwise lower bound above threshold.
- [ ] Calibration N=80 completed; likelihood table frozen.
- [ ] Primary and co-primary outcomes fixed.
- [ ] Analysis plan includes a null-result rule.
- [ ] Multiverse and prior sensitivity pre-specified.
- [ ] Independent statistician named.
- [ ] Adversarial collaborators signed.
- [ ] Systematic review completed with dual screening and PRISMA flow.

## 2. Ethics and data

- [ ] PI and institution named.
- [ ] Ethics approval number.
- [ ] Consent form.
- [ ] Data management plan.
- [ ] DPIA screening.
- [ ] Compensation and recruitment plan.
- [ ] Data-use agreement for sharing.
- [ ] No participant data in the repository.

## 3. Registration

- [ ] OSF/registration platform selected.
- [ ] Protocol version and date.
- [ ] Code SHA frozen.
- [ ] Analysis script hashed.
- [ ] Deviation log template.
- [ ] Embargo and data-sharing plan.

## 4. Manuscript

- [ ] Stage 1 manuscript complete.
- [ ] Figures generated from canonical artifacts.
- [ ] References verified.
- [ ] Authorship, CRediT, COI, funding.
- [ ] Cover letter.
- [ ] Claim audit passes.

## 5. Operations

- [ ] Target-scale compute budget approved.
- [ ] Recruitment budget approved.
- [ ] Lab deployment tested.
- [ ] Backup/restore tested.
- [ ] Incident response contact.
- [ ] Timeline and stop rules.
